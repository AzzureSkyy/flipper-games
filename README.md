# Flipper Games

Pong and Space Invaders for the Flipper Zero.

## Games
- **pong**: Up/Down move, OK pause/restart, Back exit. First to 7 wins.
- **space_invaders**: Left/Right move, OK fire/restart, Back exit. 3 lives.

## Build
Copy a game folder into `applications_user/` of the firmware and run `./fbt fap_pong` / `./fbt fap_space_invaders`, or run `ufbt` inside the game folder. Copy the `.fap` to `SD:/apps/Games/`.
